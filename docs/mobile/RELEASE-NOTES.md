Cere Mobile pairs with a Cere desktop broker implementing mobile protocol 1.0 (`0.1.0/mobile-v1`). Android 11 or newer is required; the build targets Android 17.

The native companion includes Cere's face icon and desktop palette, scoped conversations, Markdown, drafts, reviewed actions and approvals, image uploads, desktop controls, memory notes and settings. The desktop must remain awake and reachable over your LAN or existing VPN. Monitoring uses a foreground notification, without Google Play services; battery/profile/force-stop restrictions can delay or prevent delivery.
